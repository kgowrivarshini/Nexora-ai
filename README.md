# Nexora AI

Nexora AI is a responsive college-assistant web app with a browser UI and a Node.js API server. The server uses the Firebase Admin SDK for verified sessions.

## Requirements

- Node.js 18 or newer
- Firebase authentication configuration for sign-in
- Server-side environment variables configured as needed

## Run locally

1. Open this project folder in VS Code.
2. Open the integrated terminal.
3. Install dependencies and start the server:

```powershell
npm install
npm start
